# Port Log - Sprint 1

## Objetivo
Aplicar conocimientos de versionado, organización y análisis exploratorio de datos
con pandas sobre un dataset real de operaciones portuarias.

## Introducción y contexto
El Puerto Fluvial de Rosario es uno de los complejos portuarios más importantes de
América del Sur. Su sistema de registro de movimientos fue migrado desde un sistema
heredado de los años '90 que acumuló inconsistencias en fechas, matrículas y valores
numéricos. En este sprint se analizan y depuran esos datos para poder incorporarlos
al nuevo sistema.
